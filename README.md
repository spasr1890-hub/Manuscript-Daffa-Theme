# Manuscript-Daffa Theme untuk OJS 3.5

Child theme dari **Default Theme** OJS 3.5, dibangun dari [Manuscript (pkp/defaultManuscript)](https://github.com/pkp/defaultManuscript), cabang `stable-3_5_0`. Tampilan Manuscript (tata letak "kertas", font lokal Montserrat/Noto Serif) tetap, ditambah fitur di bawah. Tidak ada template inti OJS yang disalin: tema menyiapkan data saat halaman ditampilkan (`handleDisplay`) lalu mengubah HTML hasil template Default Theme lewat *output filter* Smarty. Tambahan aset: satu berkas CSS kecil (`styles/manuscriptDaffa.css`), satu skrip publik kecil (`js/manuscriptDaffa.js`), satu skrip admin (`js/manuscriptDaffaAdmin.js`), dan bendera SVG lokal. Tidak ada font eksternal.

## Pemasangan

1. Folder plugin **harus** bernama `manuscriptDaffa`: `plugins/themes/manuscriptDaffa` (sesuai `<application>` di `version.xml` dan namespace PHP). Nama tema yang tampil di OJS adalah **Manuscript-Daffa**; folder tidak memakai tanda hubung karena nama folder juga menjadi bagian namespace PHP, dan PHP tidak mengizinkan tanda hubung di namespace.
   - Lewat unggah: buat arsip yang berisi folder `manuscriptDaffa/` (mis. `tar -czf manuscriptDaffa.tar.gz manuscriptDaffa`), lalu *Website → Plugins → Upload A New Plugin*.
   - Lewat server: salin isi repositori ini ke `plugins/themes/manuscriptDaffa`.
2. Aktifkan di *Website → Plugins*, lalu pilih di *Website → Appearance → Theme*.
3. (Opsional) Pilih **Negara asal jurnal** di halaman yang sama untuk menampilkan persentase penulis asing.

Tema ini tidak bentrok dengan plugin Manuscript bawaan (`defaultManuscript`); keduanya bisa terpasang, yang dipakai adalah yang dipilih sebagai tema.

## Fitur

- **Palet warna mengikuti warna pilihan di OJS.** *Colour* (warna dasar) dan *Accent Colour* dari halaman *Appearance → Theme* dipakai oleh gaya Manuscript (LESS) dan oleh semua elemen baru tema ini (variabel CSS `--msd-primary` dan `--msd-accent`).

- **Afiliasi dan negara di bawah nama penulis** pada halaman artikel. Negara diambil dari kolom *Country* pada metadata penulis dan selalu ditambahkan di belakang afiliasi dengan tanda koma pada baris yang sama, mis. "Universitas Indonesia, Indonesia", juga ketika afiliasi sudah menyebut negara (mis. "Universitas Pendidikan Indonesia, Indonesia"). Penulis tanpa afiliasi mendapat baris negara sendiri di bawah nama. Tema menyisipkan negara pada halaman yang sudah dirender (penulis dicocokkan lewat urutan dan nama yang dicetak template), sehingga data penulis dan template Default Theme tidak diubah. Jarak nama, afiliasi, dan negara dirapatkan, dengan jarak jelas antar penulis.

- **Badge kutipan Dimensions** di halaman artikel, tepat di atas baris DOI (hanya untuk artikel yang punya DOI), sejajar dengan teks di sekitarnya. Tema membaca DOI artikel dan menyisipkan badge resmi Dimensions (`badge.dimensions.ai`, gratis, tanpa API key); angka kutipan diambil browser pengunjung dari Dimensions, bukan oleh server jurnal, dan badge tetap tampil walau kutipannya 0 (tidak tampil hanya bila Dimensions belum mengenal DOI itu sama sekali). Efek samping: halaman artikel memuat satu skrip dari domain pihak ketiga itu; skrip ini baru dimuat saat badge mendekati layar (sekitar 300 px sebelum terlihat), sehingga tidak memperlambat tampilan awal halaman. Tanpa JavaScript badge tidak tampil. Daftar artikel di beranda/terbitan tidak diberi badge. Untuk mematikan, hapus centang *Badge kutipan Dimensions* di **Fitur tema** (lihat di bawah).

- **Cakupan terbitan** (*Issue Coverage*) pada halaman terbitan dan beranda: total artikel dan **total halaman** (jumlah halaman semua artikel dari kolom *Pages*; "863-875" dihitung 13 halaman, angka tunggal 1, huruf diabaikan, kolom kosong tidak dihitung, dan bila tidak ada artikel yang berhalaman, total halaman disembunyikan), jumlah penulis dan negara, serta daftar negara dengan bendera dan jumlah penulis, mis. "Issue Coverage: 45 Author(s) from 2 Country(s)". Kotak ini ditempatkan di sebelah kanan cover terbitan (di layar 768 px ke atas), di atas deskripsi dan tanggal terbit; di layar kecil mengikuti urutan bawaan. Setiap penulis dihitung satu kali per terbitan (nama yang sama dengan email yang sama; dua penulis berbeda yang memakai satu alamat email tetap dihitung sendiri-sendiri beserta negaranya). Bendera berupa SVG lokal (`flags/`) yang hanya dimuat untuk negara yang tampil.

- **Tombol Pilih Semua / Batal Pilih di sisi admin** (OJS back end, bukan situs publik): di atas daftar artikel halaman ekspor **Crossref** (`#submissionsListGridContainer`) dan di atas tabel **Tasks/Notifikasi** (`table[id*="tasknotification"]`). Skrip terpisah `js/manuscriptDaffaAdmin.js` hanya dimuat di halaman admin untuk pengguna yang sudah login, tidak dimuat di situs publik, dan tidak melakukan apa pun di halaman yang tidak punya dua daftar itu. Daftar yang dimuat belakangan lewat AJAX ikut ditangani (pemantau perubahan halaman dengan jeda 150 ms), kotak centang yang nonaktif dilewati, dan label mengikuti bahasa (Select all / Clear selection; Pilih Semua / Batal Pilih). Jika skrip lama masih terpasang (tombol `#btnSelectAllCrossref` / `#btnSelectAllTasks`), tema tidak menambah tombol kedua; sebaiknya hapus skrip lama setelah tema ini bekerja. Tema ini harus menjadi tema aktif untuk jurnal agar tombolnya muncul.

- **Ukuran file di daftar file admin**: di daftar file *Workflow* (Submission, Review, Copyediting, Production), *Author Dashboard* (keduanya di dasbor OJS 3.5), dan halaman **reviewer** (*Download & Review*), ukuran tiap file tampil kecil di bawah jenisnya (di halaman reviewer di bawah tanggal, karena daftarnya tanpa kolom jenis) (mis. "Article Text" lalu "8.0 MB"); file 5 MB ke atas ditandai merah tebal agar mudah dikenali (sering karena font tertanam di Word). Ukuran dibaca langsung dari disk server dengan satu kueri (`submission_files` + `files`), tanpa mengunduh file dan tanpa tercatat sebagai unduhan; hanya untuk naskah di jurnal yang sedang dibuka dan hanya untuk pengguna yang memang terlibat: manajer jurnal/admin dan editor/asisten yang ditugaskan mendapat semua file naskah itu, penulis mendapat file yang terlihat di dasbor penulis dan unggahannya sendiri, reviewer hanya mendapat ukuran file ulasannya sendiri (file yang ditugaskan dan lampirannya), bukan file lain dari naskah itu. Skrip admin meminta ukuran sekali per naskah per pemuatan halaman (lewat parameter `manuscriptDaffaFileSizes` pada halaman *About this Publishing System* jurnal, yang dijawab tema dengan JSON); halaman publik tidak terpengaruh. File yang diunggah setelah halaman dibuka baru menampilkan ukuran setelah halaman dimuat ulang. Ambang 5 MB: konstanta `LARGE_FILE_BYTES`.

- **Penulis asing (persentase)** di Issue Coverage ("Foreign authors: 9 (12%)") dan di kartu Archives ("12% foreign" di bawah jumlah penulis). Perlu dipilih sekali di **Website → Appearance → Theme → Negara asal jurnal**, daftar pilihan dengan nama negara lengkap seperti pada formulir penulis (mis. Indonesia; nama mengikuti bahasa antarmuka, daftar disimpan sehari); belum dipilih = angka tidak tampil. Bila daftar negara tidak bisa dimuat, kolomnya berubah menjadi isian teks untuk kode dua huruf (mis. `ID`). Persentase dihitung dari penulis yang negaranya dikenal (bukan dari semua penulis), tidak pernah 0% bila ada penulis asing, dan ikut cache (kunci memuat negara asal, jadi mengganti isian langsung berlaku).

- **Negara dari afiliasi bila kolom *Country* kosong.** Untuk hitungan penulis, negara, dan bendera (Issue Coverage dan kartu Archives), bagian terakhir afiliasi setelah koma dicocokkan dengan nama negara (bahasa antarmuka dan Inggris, serta singkatan umum seperti USA, UK, UAE, Korea Selatan). "Universitas Indonesia, Depok, Indonesia" dibaca Indonesia; "Universitas Indonesia" saja (tanpa negara di ujung) tidak ditebak. Kolom *Country* yang terisi selalu diutamakan, dan halaman artikel tidak berubah (negara di bawah nama penulis tetap dari kolom *Country*). Banyaknya penulis yang negaranya ditebak muncul di komentar diagnosis admin (`countries taken from the affiliation`).

- **Tinggi logo header** (*Website → Appearance → Theme*): 80 px (bawaan Manuscript), 100, 120, 150 px, atau **selebar header** (banner di bawah menu pengguna). Hanya untuk layar 992 px ke atas; di layar kecil header tetap ringkas (logo maks. 30 px). Unggah logo sekitar dua kali ukuran tampil agar tajam, mis. 1650 × 160 px untuk 80 px, atau sekitar 2200 px lebar untuk banner selebar header.

- **Ukuran huruf daftar artikel** (*Website → Appearance → Theme*): Kecil, Sedang (bawaan), Besar, Sangat besar. Judul, nama penulis, nomor halaman, tombol aksi, dan abstrak pada daftar artikel (beranda, daftar isi terbitan, hasil pencarian) berubah bersama dengan satu faktor skala (`--msd-list-scale`, 0,9 / 1 / 1,12 / 1,25), jadi proporsinya tetap.

- **Pemuatan gambar**: gambar header (logo jurnal) diberi `fetchpriority="high"` agar diambil lebih dulu, dan sampul terbitan di halaman Archives, kecuali yang pertama, diberi `loading="lazy"` sehingga baru dimuat saat mendekati layar. Gambar dan iframe di **sidebar dan footer** (logo indeksasi, banner, video) juga diberi `loading="lazy"`, kecuali penghitung pengunjung (Flag Counter, StatCounter, Histats, ClustrMaps, dan sejenisnya, lihat `COUNTER_PATTERN`) supaya hitungannya tidak berkurang. Atribut `loading` atau `fetchpriority` yang sudah ada tidak ditimpa.

- **Kartu statistik di halaman Archives** (menggantikan plugin *Author Origins*, tanpa peta dan tanpa halaman peta): di bawah judul tiap terbitan tampil jumlah **penulis** (unik per terbitan), jumlah **negara** beserta sampai 6 bendera (selebihnya "+N", konstanta `ARCHIVE_FLAG_LIMIT`), dan jumlah **artikel** (dengan **total halaman** semua artikelnya di bawahnya). Data dihitung dari kolom *Country* penulis (atau afiliasi, lihat di atas), dicache per terbitan (lihat *Keandalan dan kecepatan*), dan memakai bendera lokal tema. Kartu hanya dipasang bila jumlah blok terbitan di halaman sama dengan jumlah terbitan (template bawaan); jika plugin Author Origins masih aktif, tema tidak menambah kartu lagi supaya tidak dobel. Setelah memastikan kartu tema tampil, plugin Author Origins boleh dinonaktifkan.

- **Baris aksi di bawah nama penulis** pada daftar artikel (daftar isi terbitan, beranda, hasil pencarian), meniru Portal Garuda: *Show Abstract | Download PDF | DOI: 10.xxxx/… | Check in Google Scholar*, ditampilkan sebagai tombol pil putih dengan bingkai abu-abu tipis, teks abu-abu, dan ikon garis kecil di depannya (berubah warna teal seperti judul artikel saat disorot atau saat abstrak terbuka; warna teal diatur lewat `--msd-link` di `styles/manuscriptDaffa.css`). Antar artikel pada daftar diberi garis pembatas tipis (tidak setelah artikel terakhir; hapus bagian "Thin divider" di `styles/manuscriptDaffa.css` untuk mematikannya). Judul artikel pada daftar diberi tambahan +2 px (`--msd-title-bump` di `styles/manuscriptDaffa.css`). *Show Abstract* membuka dan menutup abstrak di tempat (butuh JavaScript; tanpa JavaScript tautannya membuka halaman artikel). Tombol "PDF" bawaan artikel dihapus dan tautannya dipindahkan ke *Download PDF* (tombol galley lain, mis. HTML, tetap ada). Jika halaman tidak memuat tombol PDF (mis. hasil pencarian), tautan unduhan galley PDF dipakai; jika artikel tidak punya galley PDF, tombol tidak ditampilkan. *Check in Google Scholar* mencari judul tepat di Google Scholar. Tautan yang datanya tidak ada (mis. tanpa abstrak atau galley) tidak ditampilkan. Tidak ada tautan "Original Source". Jarak judul ke penulis dan penulis ke baris aksi sama (`--msd-list-gap`, bawaan 0,2rem). Tombol **DOI: 10.xxxx/…** (teks DOI lengkap, membuka doi.org di tab baru) tampil di sebelah kiri Google Scholar untuk artikel yang punya DOI; artikel tanpa DOI tidak mendapat tombol itu.

- **Terbitan terkini di beranda dilipat** menjadi 5 artikel pertama (urutan menurut nomor halaman). Tombol **Read more** (*Selengkapnya*) membuka seluruh artikel terbitan itu langsung di halaman yang sama, memanjang ke bawah (bukan pindah halaman), dan tombolnya berubah menjadi **Show less** (*Tampilkan lebih sedikit*) di bagian paling bawah untuk melipatnya kembali. Semua artikel sudah ada di halaman (yang tersembunyi diberi atribut `hidden`), jadi tidak ada pemuatan tambahan. Tombol rapat 8 px di bawah artikel terakhir yang terlihat. Bagian yang seluruh artikelnya tersembunyi ikut disembunyikan dengan judulnya. Tanpa JavaScript tombol menjadi tautan ke halaman terbitan. Tombol "View All Issues" bawaan tetap di bawahnya. Jumlah yang terlihat diatur lewat konstanta `HOME_ARTICLE_LIMIT` di `ManuscriptDaffaThemePlugin.php`.

- **Artikel diurutkan menurut nomor halaman awal** di beranda (sebelum 5 artikel pertama dipilih) dan di halaman terbitan, per bagian (mis. Research Articles tetap di bagiannya). Angka pertama dari rentang halaman dipakai (`1029-1038` → 1029, `e12` → 12), diurutkan sebagai angka. Artikel tanpa nomor halaman diletakkan di akhir bagiannya dengan urutan semula; nomor halaman yang sama mempertahankan urutan semula. Pengaturan *Table of Contents* di OJS tidak berlaku lagi di dua halaman itu; halaman pencarian dan arsip tidak diubah.

- **Kartu kategori di beranda**, tepat di bawah bagian About (bila About tidak ditampilkan: di atas pengumuman/terbitan terkini): satu kartu per Kategori OJS (*Settings → Journal → Categories*) yang punya artikel di **Current Issue**. Kartu menampilkan nama kategori dan jumlah artikel di terbitan itu; klik kartu untuk membuka daftar artikelnya (maks. 20, konstanta `CATEGORY_ARTICLE_LIMIT`; selebihnya lewat tautan ke halaman kategori). Kategori tanpa artikel di Current Issue disembunyikan, jadi daftar berubah mengikuti terbitan aktif; tanpa Current Issue atau tanpa kategori, kartu tidak muncul. Artikel masuk ke kategori lewat tab *Publication → Metadata/Categories* artikelnya. Kartu memakai elemen `<details>`, jadi tetap berfungsi tanpa JavaScript. Jika kartu tidak muncul, lihat komentar `<!-- manuscriptDaffa ... -->` di sumber halaman (saat login sebagai manajer jurnal/admin), baris `categories with articles in current issue`.

- **Deskripsi meta otomatis** (`<meta name="description">`, teks di bawah judul pada hasil Google) untuk halaman yang belum punya: abstrak di halaman artikel, judul dan deskripsi terbitan di halaman terbitan, selain itu nama dan deskripsi jurnal (maks. 160 karakter, dipotong di batas kata). Halaman yang sudah punya deskripsi meta tidak diubah.

- **Pratinjau tautan (Open Graph)**: tag `og:*` dan `twitter:*` di setiap halaman publik, sehingga tautan yang dibagikan ke WhatsApp, Facebook, Telegram, X, dan lainnya tampil dengan judul, deskripsi, dan gambar. Halaman artikel memakai judul artikel, abstrak, tanggal terbit (`article:published_time`), dan gambar sampul artikel (bila tidak ada: sampul terbitan); halaman terbitan memakai identitas terbitan dan sampulnya; halaman lain memakai judul halaman. Bila tidak ada sampul, dipakai *Journal thumbnail* (*Settings → Website → Appearance*), lalu logo header. Gambar sebaiknya minimal 600 px lebar (ideal 1200 × 630 px) agar tampil besar di pratinjau. Bila plugin lain sudah menambahkan tag Open Graph, tema tidak menambah tag kedua.
- Nama negara mengikuti bahasa antarmuka OJS.
- Teks Indonesia dan Inggris (`locale/id`, `locale/en`); terjemahan Manuscript lain tetap ada untuk nama dan opsi tema.

## Struktur

| Berkas | Isi |
|---|---|
| `ManuscriptDaffaThemePlugin.php` | Opsi tema, aset, `handleDisplay` (data halaman, urutan artikel) dan *output filter* (semua perubahan HTML) |
| `classes/IssueStats.php` | Hitungan artikel, halaman, penulis, negara, penulis asing (cache 1 hari, diperbarui otomatis saat artikel terbitan berubah) |
| `classes/Countries.php` | Nama negara sesuai bahasa, bendera lokal, tebakan negara dari afiliasi |
| `classes/FileSizes.php` | Ukuran file untuk daftar file admin, beserta pemeriksaan hak akses |
| `classes/Html.php` | Fungsi bantu pengubah HTML |
| `styles/manuscriptDaffa.css` | Gaya fitur baru (selain gaya Manuscript di `styles/*.less`) |
| `js/manuscriptDaffa.js` | Show Abstract, Read more/Show less |
| `js/manuscriptDaffaAdmin.js` | Pilih Semua/Batal Pilih, ukuran file |
| `flags/` | Bendera SVG dari [flag-icons](https://github.com/lipis/flag-icons) (MIT, lihat `flags/LICENSE`) |

## Keandalan dan kecepatan

- **Fitur tema bisa dimatikan satu per satu** di *Website → Appearance → Theme → Fitur tema*: negara di belakang afiliasi, badge Dimensions, Cakupan Terbitan, urutan menurut halaman, lipatan beranda, kartu kategori, kartu Arsip, tombol aksi daftar artikel, deskripsi meta, pratinjau tautan (Open Graph), pengaturan pemuatan gambar, serta tombol *Pilih Semua* dan ukuran file di sisi admin. Fitur yang dimatikan tidak mengubah halaman dan tidak menjalankan kuerinya (mis. statistik terbitan tidak dihitung bila Cakupan Terbitan dan kartu Arsip mati). Fitur yang ditambahkan di versi tema berikutnya otomatis menyala, juga di jurnal yang sudah pernah menyimpan daftar ini. Komentar diagnosis menampilkan fitur yang mati (`features switched off`) dan menandai langkahnya `disabled in the theme settings`.
- **Statistik terbitan (Cakupan Terbitan, kartu Arsip) dicache 1 hari, tetapi langsung diperbarui saat artikel terbitan itu berubah.** Kunci cache memuat cap kecil per terbitan dari satu kueri: jumlah artikel terbit, waktu perubahan terakhir publikasinya, jumlah dan id penulis terbaru, serta waktu perubahan terbitan. Menerbitkan, menarik, atau mengubah artikel (di OJS 3.5 artikel terbit harus ditarik atau dibuat versi baru sebelum diedit) membuat cap berubah sehingga statistik dihitung ulang pada kunjungan berikutnya; tanpa perubahan, statistik diambil dari cache. Mengubah *Negara asal jurnal* juga langsung berlaku. Untuk menghitung ulang seketika, manajer jurnal/admin dapat membuka halaman dengan tambahan `?manuscriptDaffaRefresh=1` (mis. `…/issue/archive?manuscriptDaffaRefresh=1`); parameter ini diabaikan untuk pengunjung lain.
- **Setiap fitur berjalan terpisah.** Persiapan data dan setiap perubahan halaman (negara penulis, badge, Issue Coverage, lipatan beranda, kartu kategori, kartu arsip, tombol aksi, gambar, deskripsi meta) dijalankan sendiri-sendiri. Bila satu langkah gagal (mis. data artikel yang tidak lazim), halaman tetap mendapat hasil langkah lainnya, dan galatnya dicatat di log galat PHP (`manuscriptDaffa: <fitur> failed on <template>: …`). Satu artikel yang bermasalah di daftar artikel juga tidak menghilangkan tombol aksi artikel lain.
- **Komentar diagnosis per fitur.** Saat login sebagai manajer jurnal atau admin situs, sumber halaman (Ctrl+U) memuat komentar `<!-- manuscriptDaffa <versi> … -->` berisi status tiap fitur di halaman itu, mis. `author countries: added to 4 of 4 authors (0 without Country, 0 not matched by name)`, `Dimensions badge: skipped: the article has no DOI`, `article action rows: added to 5 of 5 articles, PDF button moved for 5`, atau `ERROR …` bila sebuah langkah gagal.
- **Font.** Montserrat memakai `font-display: swap` (teks langsung tampil dengan font cadangan sambil font diunduh), dan Montserrat Bold (judul, menu) dimuat lebih awal lewat `<link rel="preload">` di halaman publik.
- **Alamat CSS/JS memuat versi tema** (`?v=<versi>`), jadi setelah pembaruan tema browser dan Cloudflare langsung mengambil berkas baru.

## Catatan

- Tema mengenali markup template Default Theme OJS 3.5. Jika ada plugin lain yang mengganti template yang sama (mis. `article_summary.tpl`), bagian yang tidak dikenali dibiarkan apa adanya.
- Belum diuji pada instalasi OJS 3.5 yang berjalan; perubahan HTML sudah diuji terhadap markup template Default Theme 3.5. Laporkan jika ada bagian yang tidak muncul, sertakan komentar diagnosis `<!-- manuscriptDaffa ... -->`.

## Pengembangan dan rilis

- **Rilis otomatis.** Setiap kali `main` memuat versi baru di `version.xml` (mis. `1.0.2.0`) yang belum punya rilis, GitHub Actions (`.github/workflows/release.yml`) menjalankan uji, membuat `manuscriptDaffa-<versi>.tar.gz` (folder `manuscriptDaffa/`, tanpa berkas uji), dan menerbitkannya di halaman **Releases** repositori. Untuk memperbarui jurnal: unduh berkas itu dari *Releases*, lalu *Website → Plugins → Upgrade* di baris Manuscript-Daffa (atau *Upload A New Plugin* untuk pemasangan pertama). Jadi cukup naikkan nomor di `version.xml` pada setiap perubahan tema.
- **Uji otomatis** (`.github/workflows/ci.yml`) di setiap push dan pull request:
  - sintaks PHP dan JavaScript, serta `php tests/run.php` (filter HTML dan fungsi bantu terhadap markup template Default Theme 3.5) di PHP 8.2, 8.3, dan 8.4;
  - `tests/smarty-filter.php` dengan Smarty 4.5.5 (versi OJS 3.5): memastikan nama *output filter* tema tidak bentrok dengan filter plugin lain;
  - `tests/check-templates.php` terhadap OJS `3_5_0-6` dan cabang `stable-3_5_0`: memastikan template OJS masih memuat markup yang dicari tema, sehingga perubahan template di rilis OJS berikutnya ketahuan sebelum tema dipasang; serta kompilasi LESS tema bersama Default Theme.
- **Menjalankan uji sendiri:** `php tests/run.php`; `php tests/check-templates.php /path/ke/ojs`; `php tests/smarty-filter.php /path/ke/smarty/libs`.
